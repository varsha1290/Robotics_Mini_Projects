# Robotics Mini Projects

A single portfolio repository for 83 embedded systems, sensors, robotics, IoT, computer vision, ROS 2, simulation, and automotive learning projects.

## Categories

1. `01_Arduino_Basics` — microcontroller fundamentals and basic output control
2. `02_Sensors_and_Instrumentation` — sensor interfacing and measurement
3. `03_Mobile_Robotics` — robot cars, mobile platforms, and robotic arm projects
4. `04_IoT_and_Automation` — ESP32, connected monitoring, and automation
5. `05_Communication_Protocols` — UART, I2C, SPI, CAN, Bluetooth, Wi-Fi, ESP-NOW
6. `06_Raspberry_Pi_and_Computer_Vision` — Raspberry Pi, OpenCV, and vision projects
7. `07_ROS2_and_Simulation` — ROS 2, Turtlesim, Gazebo, and teleoperation
8. `08_Advanced_Robotics` — IMU, PID, LiDAR, mapping, and tracking
9. `09_Vehicle_and_Automotive_Projects` — vehicle monitoring and black-box projects

## Provenance and testing

Where original source files, photographs, or test records are unavailable, code and documentation are explicitly marked as reconstructed reference implementations. Reconstructed work is not represented as original historical source code. Hardware testing is only claimed when a test record is actually completed.

Each project folder contains its own README, source, connection guide, setup instructions, and test procedure as applicable.
